# Website

Plain HTML/CSS/JS, with no build step.

## Run locally

```sh
./serve.sh        # http://localhost:8000
./serve.sh 3000   # custom port
```

Or just open `index.html` in a browser.

## Files

- `index.html` is the page structure
- `style.css` holds the styles (colors live in `:root` variables)
- `script.js` holds the behavior
- `assets/` is for images, fonts, etc.
